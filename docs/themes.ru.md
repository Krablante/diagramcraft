# Темы и свои темы

[English](./themes.md) · [Русский](./themes.ru.md) · [Главная](../README.ru.md)

Тема — это JSON-набор токенов: шрифты, цвета, заливки узлов, обводки, тени, стили связей, оформление зон, фон и отступы по умолчанию. Рендерер реализует фиксированный набор примитивов, а темы собирают из них композицию. Поэтому темы могут выглядеть по-настоящему по-разному, не требуя правок кода.

Каждая встроенная тема сливается поверх [`themes/_base.json`](../themes/_base.json), где лежат все значения по умолчанию. Своей теме достаточно переопределить то, что она меняет, но у неё должны быть непустые `id` и `title`. Команда `dorpie themes classic` печатает полностью раскрытую тему — удобно, когда нужно увидеть все токены сразу.

```sh
dorpie themes                 # список id и описаний
dorpie themes paper > my-theme.json
dorpie render spec.json --theme my-theme.json
```

Значение темы, которое заканчивается на `.json` или содержит `/`, считается путём к файлу и загружается с диска. Относительные пути разрешаются от текущего рабочего каталога, а не от файла спеки.

Точечные правки живут в `style` и глубоко сливаются с выбранной темой:

```json
{
  "theme": "classic",
  "style": {
    "node": { "radius": 14, "shadow": null },
    "edge": { "stroke": { "color": "#7c3aed" } },
    "fonts": { "title": { "family": "JetBrains Mono" } }
  }
}
```

Массивы (например, стопы градиентов) заменяются целиком, а не сливаются.

## Встроенные темы

| Id | Назначение |
| --- | --- |
| `classic` | нейтральные блок-схемы; белый холст, чёткие линии, синий акцент |
| `mono` | чёрно-белая печать; моноширинный шрифт, прямые углы, без цвета |
| `light` | мягкий серый фон, белые узлы и сдержанный синий; светлые документы и слайды |
| `dark` | графитовые поверхности, чёткие контуры и светло-синий акцент; тёмные документы и слайды |
| `paper` | светлая бумажная фактура, антиква, тёплые чернила и лёгкий рельеф; оформление для статей |
| `vivid` | приглушённые заливки по видам узлов, тёмные подписи и зелёный акцент; цветовые блок-схемы |
| `blueprint` | тонкая синяя сетка, непрозрачные формы, моноширинные подписи и открытые стрелки; чертежи |
| `copper` | графитовая фактура, медные блики и объёмные поверхности; презентации в тёплой палитре |

Classic, Mono, Light, Dark и Vivid используют плоские заливки без фильтров. Paper и Copper добавляют тонкую фактуру и небольшие тени; Blueprint сохраняет малоконтрастную сетку за пределами фигур. Все темы используют встроенные шрифты и работают локально.

`glass` и `midnight` — совместимые id для `light` и `dark`; в списке тем их нет. `getTheme` и новые экспорты возвращают id темы-замены. Сохранённые версии исходников сохраняют прежнюю спеку, существующие экспорты — файлы и снимки раскрытых тем. Чтобы воспроизвести прежнее оформление, передайте архивный `theme.json` как файл своей темы.

`dorpie themes --json` дополнительно возвращает `description`, `tags`, `title` и `order` каждой темы. Метаданные не влияют на рендер; исключение — `order`, он задаёт порядок в списках.

## Справочник токенов

### `canvas`

| Токен | Смысл |
| --- | --- |
| `background` | Заливка холста. |
| `blobs` | Массив мягких цветных полей: `{ cx, cy, r, color, opacity }`, координаты `0..1`. `null` отключает. |
| `texture` | Наложение `noise`, `grid` или `dots`; `null` отключает. |
| `vignette` | Затемнение краёв `{ color, opacity, size }`; `null` отключает. |
| `padding` | Расстояние от содержимого до края холста. |
| `minWidth` | Минимальная ширина содержимого без учёта padding. |
| `radius` | Радиус скругления холста. `0` — прямые углы. |

Объекты заливки:

```jsonc
{ "type": "solid", "color": "#ffffff" }
{ "type": "linear", "angle": 120, "stops": [[0, "#e8e9ff"], [1, "#ffe9f2"]] }  // angle: 0 = слева→вправо, 90 = сверху→вниз
{ "type": "radial", "center": [0.5, 0.4], "radius": 0.8, "stops": [[0, "#fff"], [1, "#00000000"]] }
```

Текстуры:

```jsonc
{ "type": "noise", "opacity": 0.05, "scale": 1, "seed": 7 }
{ "type": "grid",  "color": "rgba(125,211,252,0.12)", "size": 22, "width": 1 }
{ "type": "dots",  "color": "rgba(148,163,184,0.12)", "size": 26, "radius": 1 }
```

### `fonts`

По одному токену на роль: `title`, `subtitle`, `node`, `note`, `edge`, `zone`, `footer`.

| Токен | Смысл |
| --- | --- |
| `family` | Семейство шрифта. |
| `size` | Размер в пикселях. |
| `weight` | Числовая насыщенность (400, 500, 600, 700). |
| `color` | Цвет заливки. |
| `lineHeight` | Множитель высоты строки, по умолчанию `1.35`. |
| `spacing` | Межбуквенный интервал в пикселях. |
| `uppercase` | Только для `zone`: выводить подпись заглавными. |

Встроенные семейства: **Inter** (400/500/600), **Source Serif 4** (400/600), **JetBrains Mono** (400/700). Если запрошена другая насыщенность, выбирается ближайшая встроенная. Метрики покрывают латиницу, греческий, кириллицу, обычную пунктуацию и стрелки, поэтому подписи в этих письменностях корректно измеряются и переносятся.

PNG растрирует текст из встроенных TTF-файлов и не зависит от системных шрифтов. SVG ссылается на имя семейства; если у зрителя такого шрифта нет, браузер подставит системный — для SVG это нормально. Если тема использует семейство, которого нет среди встроенных, `--system-fonts` разрешает PNG-рендереру поискать его в системе, но результат начинает зависеть от машины.

Чтобы добавить шрифт в форке: положите TTF в `assets/fonts/`, добавьте файл в карту `known` в `scripts/build-metrics.mjs`, выполните `npm run metrics` и сошлитесь на семейство в теме.

### `node`

| Токен | Смысл |
| --- | --- |
| `minWidth` | Минимальная ширина содержимого; горизонтальные отступы добавляются вокруг него. |
| `maxTextWidth` | Ширина, после которой подпись переносится. |
| `padX`, `padY` | Внутренние отступы. |
| `radius` | Радиус скругления прямоугольников. |
| `fill` | Заливка обычных узлов. |
| `stroke` | `{ color, width, dash }`; `dash` — массив вида `[5, 4]` или `null`. |
| `shadow` | `{ color, opacity, blur, y }` или `null`. |
| `glow` | `{ color, blur }` или `null`; мягкий ореол. |
| `shine` | Наложение-блик для стеклянных карточек или `null`. |
| `kinds.<kind>` | Для конкретного вида: `fill`, `stroke`, `shadow`, `glow`, а также `size` для `connector` и `junction`. |
| `accent` | `{ fill, stroke, text: { color }, note?: { color } }` для узлов с `accent: true`. Вторичный текст следует цвету акцентной подписи, если его не переопределяет `note.color`. |

### `edge`

| Токен | Смысл |
| --- | --- |
| `stroke` | `{ color, width, dash }`. |
| `cornerRadius` | Скругление ортогональных маршрутов. `0` — жёсткие углы. |
| `arrow` | `{ type: "triangle" \| "vee" \| "circle" \| "none", size, color }`; `color: null` следует цвету линии. |
| `label` | `{ fill, padX, padY, radius }` для плашки подписи; `fill: "none"` рисует голый текст. |
| `kinds.dashed` / `kinds.dotted` | Переопределения пунктира. |

### `zone`

| Токен | Смысл |
| --- | --- |
| `fill` | Заливка зоны. |
| `stroke` | `{ color, width, dash }`. |
| `radius` | Радиус скругления. |
| `pad` | Горизонтальный отступ вокруг узлов (он же минимальный жёлоб под подпись). |
| `padY` | Вертикальный отступ; держите его небольшим, чтобы соседние зоны не слипались. |
| `labelPad` | Отступ подписи. |
| `labelColor` | Переопределение цвета подписи; `null` — использовать `fonts.zone.color`. |

### `heading`, `footer`, `layout`

| Токен | Смысл |
| --- | --- |
| `heading.align` | `left`, `center` или `right`. |
| `heading.gap` | Отступ между блоком заголовка и диаграммой. |
| `heading.rule` | Акцентная линия под заголовком `{ color, width, length, gap }` или `null`. |
| `heading.subtitleGap` | Отступ между заголовком и подзаголовком. |
| `footer.gap`, `footer.align` | Отступ и выравнивание футера. |
| `layout.nodeGap` | Расстояние между узлами в одном слое. |
| `layout.rankGap` | Расстояние между слоями. |
| `layout.edgeGap` | Расстояние между связями и узлами. |
| `layout.edgeLabelGap` | Место, зарезервированное вокруг подписей связей. |

## Как написать свою тему

Минимальная своя тема — всё остальное берётся из встроенной основы:

```json
{
  "id": "sage",
  "title": "Sage",
  "description": "Light diagrams with a green accent",
  "tags": ["light"],
  "order": 20,
  "canvas": {
    "background": { "type": "solid", "color": "#f5f8f5" },
    "texture": { "type": "dots", "color": "rgba(70,109,89,0.07)", "size": 24, "radius": 1 }
  },
  "node": {
    "radius": 6,
    "stroke": { "color": "#466d59", "width": 1.4 },
    "accent": {
      "fill": { "type": "solid", "color": "#315847" },
      "stroke": { "color": "#315847", "width": 1.4 },
      "text": { "color": "#ffffff" }
    }
  },
  "edge": {
    "stroke": { "color": "#466d59", "width": 1.4 },
    "label": { "fill": "#f5f8f5" }
  }
}
```

Сохраните её как `sage.json` и рендерите с `--theme sage.json`. Обязательны только `id` и `title`; у `description`, `tags` и `order` есть разумные значения по умолчанию.

Для своей тёмной темы начните с `dorpie themes dark > my-theme.json`. Меняйте вместе все роли текста и заливки отдельных видов: одного тёмного холста с унаследованными белыми фигурами недостаточно. Не накладывайте фактуру на подписи, используйте тени умеренно. Проверяйте все формы через `examples/node-shapes.json`, а группы и пояснения в акцентных блоках — через `examples/theme-preview.json`.

Ориентиры для целостной темы:

- Дайте теме один типографический голос (одно семейство, максимум одно акцентное).
- Берите заливку, обводку и фон из одного цветового семейства; акцент используйте скупо.
- Меняйте не только цвета, но и форму стрелок и радиусы углов.
- Проверяйте тему на диаграмме с развилкой, заметкой и группой — слабые темы ломаются именно там.
- После правок темы выполняйте `npm run gallery` в репозитории, чтобы обновить картинки README.
