# Справочник по спеке

[English](./spec.md) · [Русский](./spec.ru.md) · [Главная](../README.ru.md)

Диаграмма — это один JSON-объект, и это единственный файл, который вы редактируете: SVG, PNG и ASCII всегда рендерятся из него. `dorpie schema` печатает машиночитаемую JSON-схему, а `dorpie validate` показывает все проблемы сразу, до рендера.

```jsonc
{
  "version": 1,
  "title": "Деплой",
  "subtitle": "От мержа до продакшена",
  "footer": "runbook команды",
  "theme": "paper",
  "direction": "TB",
  "layout": { "nodeGap": 42, "rankGap": 68, "edgeGap": 16 },
  "output": { "formats": ["svg", "png", "ascii"], "scale": 2 },
  "nodes": [
    { "id": "start", "kind": "terminal", "label": "Пуш в main" },
    { "id": "build", "kind": "process", "label": "Сборка и тесты" },
    { "id": "ok", "kind": "decision", "label": "Зелёный?" },
    { "id": "ship", "kind": "terminal", "label": "Выкатка" }
  ],
  "edges": [
    { "from": "start", "to": "build" },
    { "from": "build", "to": "ok" },
    { "from": "ok", "to": "ship", "label": "да" },
    { "from": "ok", "to": "build", "label": "нет", "kind": "dashed" }
  ],
  "groups": [
    { "label": "CI", "nodes": ["build", "ok"] }
  ]
}
```

## Верхний уровень

| Поле | Тип | По умолчанию | Смысл |
| --- | --- | --- | --- |
| `version` | `1` | `1` | Версия спеки. Принимается только версия 1. |
| `title` | string | — | Заголовок над диаграммой. |
| `subtitle` | string | — | Вторая строка под заголовком. |
| `footer` | string | — | Мелкая строка внизу холста. |
| `theme` | string | `classic` | Id встроенной темы или путь к файлу своей темы. |
| `direction` | `TB` \| `LR` \| `RL` \| `BT` | `TB` | Направление потока, регистр не важен. Для пайплайнов и таймлайнов используйте `LR`. |
| `layout` | object | тема | Положительные отступы в пикселях: `nodeGap`, `rankGap`, `edgeGap`. |
| `style` | object | — | Глубокие переопределения поверх выбранной темы; см. [themes.ru.md](./themes.ru.md). |
| `output` | object | — | Значения по умолчанию для форматов, масштаба PNG, прозрачности и набора символов ASCII. Флаги CLI имеют приоритет. |
| `nodes` | array | обязательно | Как минимум один узел. |
| `edges` | array | `[]` | Связи между узлами. |
| `groups` | array | `[]` | Визуальные зоны вокруг групп узлов. |

Значение `theme`, которое заканчивается на `.json` или содержит разделитель пути (`/` или `\`), загружается с диска; любое другое значение должно быть id встроенной темы.

Неизвестные поля отклоняются, а путь в ошибке указывает на опечатку (`nodes[0].lable: unknown field "lable"`). Это относится и ко всем вложенным объектам ниже.

Необязательный текст, размеры узлов, значения kind/arrow и необязательные разделы верхнего уровня принимают `null` как отсутствие значения. Поэтому нормализованные сохранённые спеки проходят опубликованную JSON-схему. `accent` и `output.transparent` при наличии должны быть булевыми, отступы внутри `layout` — положительными числами. Валидатор дополнительно проверяет связи, которые JSON-схема не выражает: уникальность ID, существование концов связей, состав групп и петли на себя.

## Узлы

| Поле | Тип | По умолчанию | Смысл |
| --- | --- | --- | --- |
| `id` | string | обязательно | Уникальный id, на который ссылаются связи и группы. |
| `label` | string | `id` | Текст в узле. `\n` начинает новую строку; длинные подписи переносятся автоматически. У junction-узлов подписи быть не должно. |
| `kind` | вид узла | `process` | Форма и смысл, см. ниже. |
| `note` | string | — | Мелкая приглушённая строка под подписью. |
| `accent` | boolean | `false` | Залить узел акцентным цветом темы. |
| `color` | string | — | Сплошная заливка для этого узла. |
| `maxWidth` | number | тема | Переносить подпись при такой ширине в пикселях. |
| `width`, `height` | number | auto | Фиксированный размер; нужен редко. |

### Виды узлов

| Вид | Форма | Для чего |
| --- | --- | --- |
| `terminal` | стадион / скруглённые торцы | начало, конец, точки входа |
| `process` | скруглённый прямоугольник | действия, шаги, модули |
| `decision` | ромб | ветвления «да/нет» и другие развилки |
| `data` | параллелограмм | входы, выходы, данные |
| `document` | прямоугольник с волнистым низом | документы, отчёты, файлы |
| `database` | цилиндр | хранилища, базы, кеши |
| `connector` | круг | соединители на странице, точки слияния с буквой |
| `note` | лист с загнутым углом | пометки и предупреждения |
| `junction` | маленькая точка | тихие слияния (без подписи), например residual-суммы |

## Связи

| Поле | Тип | По умолчанию | Смысл |
| --- | --- | --- | --- |
| `id` | string | `e0`, `e1`, … | Необязательный id; должен быть уникальным. |
| `from`, `to` | string | обязательно | Id узлов. Петли на себя не поддерживаются; используйте junction или путь повторной попытки. |
| `label` | string | — | Короткий текст рядом со связью. Обычно `yes`/`no`/`retry`. |
| `kind` | `solid` \| `dashed` \| `dotted` | `solid` | Стиль линии. |
| `arrow` | `end` \| `both` \| `none` | `end` | Стрелки. Стрелка в junction-точку не рисуется. |
| `color` | string | тема | Переопределение цвета линии и стрелки. |

Связи автоматически прокладываются ортогональными линиями со скруглёнными углами. Параллельные связи, циклы и длинные обратные петли поддерживаются; движок раскладки резервирует место под подписи.

## Группы

Группа — это визуальная зона, нарисованная под своими узлами. На раскладку она не влияет: сначала расставьте узлы так, чтобы поток читался, затем обведите зоной фазу, подсистему или повторяющийся блок. Узел может входить только в одну группу; повторное указание — ошибка.

| Поле | Тип | По умолчанию | Смысл |
| --- | --- | --- | --- |
| `id` | string | `g0`, … | Необязательный id; должен быть уникальным. |
| `label` | string | `id` | Подпись в левом жёлобе зоны. |
| `nodes` | string[] | обязательно | Id узлов-участников, минимум один. |
| `color` | string | тема | Переопределение заливки зоны. |

## Значения вывода по умолчанию

`output` определяет, что сделает обычный `dorpie render spec.json`. Любое значение можно переопределить флагом CLI.

| Поле | Тип | По умолчанию | Смысл |
| --- | --- | --- | --- |
| `formats` | массив из `svg`, `png`, `ascii` | `["svg"]` | Форматы, которые пишутся, если не передан `--format`. |
| `scale` | number | `2` | Множитель масштаба PNG. |
| `transparent` | boolean | `false` | Убрать фон холста в PNG и SVG. |
| `charset` | `unicode` \| `ascii` | `unicode` | Набор символов для ASCII-вывода. |

```json
{ "output": { "formats": ["svg", "ascii"], "charset": "ascii", "transparent": true } }
```

## Переопределения стиля

`style` глубоко сливается с выбранной темой, поэтому можно поправить несколько токенов, не описывая тему целиком:

```json
{
  "theme": "vivid",
  "style": {
    "fonts": { "title": { "size": 32 } },
    "node": {
      "radius": 16,
      "shadow": null,
      "accent": { "fill": { "type": "solid", "color": "#0f766e" } }
    },
    "edge": { "stroke": { "color": "#0f172a", "width": 1.8 } }
  }
}
```

Массивы (например, стопы градиентов) заменяются целиком, а не сливаются.

## Проверка

`dorpie validate` показывает все проблемы сразу с JSON-путём, например:

```
spec error: 4 problems
  nodes[1].id: duplicate node id "build" (first used by nodes[0])
  nodes[2].lable: unknown field "lable"
  edges[2].to: unknown node "shiping"
  output.formats: unknown format "jpeg"; expected svg, png or ascii
```

`dorpie validate spec.json --json` печатает `{ "ok": true, ... }` для корректной спеки или `{ "ok": false, "issues": [...] }` с путями и сообщениями об ошибках. Коды возврата: `0` — успех, `2` — некорректная спека или аргументы, `1` — ошибка времени выполнения.

## Советы по читаемости

- Держите подписи короткими и конкретными; детали уносите в `note`.
- Одна мысль на узел. Длинные цепочки разбивайте.
- `decision` — только для настоящих развилок; подписывайте связи `yes`/`no`.
- Для пайплайнов используйте направление `LR`, для процедур — `TB`.
- Группы — для фаз (`Prepare`, `Publish`, `Roll out`), а не для украшения.
- 10–20 узлов на диаграмму — оптимум; больше — разбивайте или группируйте.
